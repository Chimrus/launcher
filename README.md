# ck3launcher

Лаунчер и менеджер модов для Crusader Kings III (Windows, игра из Steam).
A launcher and mod manager for Crusader Kings III (Windows, Steam version of the game).

## Скачать

**Последняя версия — 0.1.7:** [ck3launcher-0.1.7-win64.zip](https://github.com/Chimrus/launcher/releases/download/v0.1.7/ck3launcher-0.1.7-win64.zip) (50 МБ)

1. Распакуйте архив в любую свою папку (не в `Program Files`).
2. Откройте папку `ck3launcher` и запустите `ck3launcher.exe`.
3. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».

Дальше лаунчер обновляется сам.

Все версии — [Releases](https://github.com/Chimrus/launcher/releases). SHA-256 архива: `73cb9fb3ef7dbed3c171d402a3b668a600e9d20b4fd239492dcc90faa20d30b8`

## Download

**Latest version — 0.1.7:** [ck3launcher-0.1.7-win64.zip](https://github.com/Chimrus/launcher/releases/download/v0.1.7/ck3launcher-0.1.7-win64.zip) (50 MB)
